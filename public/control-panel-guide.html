📘 دليل لوحة التحكم

أكاديمي — كلية الهندسة المدنية / الجامعة التكنولوجية
دليل شامل للمشرف/المدير لاستخدام لوحة التحكم والتحكم الكامل بكافة أنظمة التطبيق دون الحاجة إلى كتابة أي كود.

🔐 1. الدخول إلى لوحة التحكم

  • المسار: من الصفحة الرئيسية اضغط بطاقة «لوحة التحكم»، أو انتقل مباشرة إلى /control-panel.
  • كلمة المرور الافتراضية: 2021 (يمكن تغييرها من داخل اللوحة نفسها — انظر القسم 3).
  • نصيحة أمنية: غيّر كلمة المرور فور أول دخول، ولا تشاركها إلا مع من يحق له الإدارة الكاملة.

الصندوقالوظيفة

👥 3. إدارة التدريسيين

  • إضافة تدريسي: الاسم الكامل + القسم + كلمة مرور مبدئية (افتراضياً 123).
  • تعديل: غيّر القسم أو الاسم، أو أعد تعيين كلمة المرور.
  • حذف: يُنقل التدريسي تلقائياً إلى ورقة archive كنسخة احتياطية.
  • تسجيل دخول التدريسي: من بطاقة «التكليفات الفردية» في الرئيسية.

🎨 4. نمط الواجهة

  • 10 ثيمات بمستوى جامعي رسمي — يُطبَّق الاختيار فوراً على كل الشاشات.
  • الوضع الليلي 🌙 / النهاري ☀️: زر واحد يعمل مع أي ثيم.
  • الوضع ثلاثي الأبعاد 🟢: يفعّل تأثيرات العمق على البطاقات.

🔐 5. كلمات المرور

  • كلمة مرور اللوحة: لدخول لوحة التحكم فقط.
  • كلمة مرور المدير: داخل نظام التكليفات الفردية للعمليات الحسّاسة.
  • كلمة مرور كل نظام: من صندوق «إظهار/إخفاء الأنظمة».
⚠️ عند تغيير أي كلمة مرور، سيُطلب إدخال كلمة مرور اللوحة الحالية للتأكيد.

📦 6. مجموعات الأنظمة

تسمح بتجميع عدة بطاقات (مثلاً كل ما يخص «الإشراف») في بطاقة واحدة على الرئيسية.

  1. اضغط «➕ إضافة مجموعة».
  2. أدخل: الاسم، الوصف، الأيقونة، اللون.
  3. حدد الأنظمة المراد ضمّها.
  4. اضغط «💾 حفظ المجموعة» — سيُطلب كلمة مرور اللوحة.
  5. ستظهر المجموعة كبطاقة موحّدة على الرئيسية.

حذف مجموعة: يعيد أنظمتها للظهور بشكل منفرد.

🧩 7. منشئ الأنظمة بدون كود

أهم ميزة في اللوحة — تُنشئ نظاماً كاملاً (واجهة، فلاتر، طباعة، صلاحيات) من جدول Google Sheets.

7.1 الحقول الأساسية

  • العنوان، الوصف، الأيقونة، اللون، ترتيب الظهور.
  • مصدر البيانات: جدول المشروع الحالي أو رابط Google Sheet خارجي.
  • معرّف الورقة (GID): الأرقام في نهاية رابط الورقة.
  • نطاق الأعمدة: مثل F:N.

7.2 الفلاتر

  • العمود بحرف Excel (مثل F).
  • نوع التحكم: قائمة منسدلة / بحث + قائمة / نص حر / نطاق رقمي (من — إلى) ✨ / نطاق تاريخ (من — إلى) ✨.
  • إلزامي؟ إن فُعّل، لا تظهر بيانات قبل الاختيار.
  • قواعد مسمّاة: خيارات جاهزة مثل «أقل من 10» أو «بين 5 و20».

7.3 الشروط والأعمدة المشتقّة

  • الشروط: لإخفاء الصفوف التي لا تحقق شرطاً (مثل H = "نظري").
  • AND / OR: طريقة الدمج.
  • الأعمدة المشتقّة: إنشاء عمود جديد بمعادلة أو تحويل قيم.

7.4 صلاحيات CRUD

لكل نظام: عرض / إضافة / تعديل / حذف — كل صلاحية مستقلة.

عند التفعيل: أزرار تعديل/حذف تظهر مجاورة لكل صف، وأزرار إضافة/بحث في أعلى الجدول، فقط للمستخدمين الذين لديهم الصلاحية.
  • أنواع الأعمدة: text / number / date / select / readonly.
  • خيارات القائمة يدوية أو مستخرَجة تلقائياً من العمود.
  • زر رابط: يعرض «افتح الملف» بدلاً من الرابط الخام.

7.5 قفل الوصول للتدريسي

  • require_teacher_auth: يفرض تسجيل الدخول.
  • teacher_column / teacher_department_column: أعمدة الاسم والقسم.
  • نطاق التصفية: name / department / name_or_department / all.

7.7 التواقيع

أضف عدة تواقيع (اسم + مسمى وظيفي) تظهر أسفل الطباعة.

👁️ 8. إظهار/إخفاء الأنظمة وحمايتها

  • مرئي / مخفي — يختفي من الرئيسية.
  • محمي بكلمة مرور — يطلبها عند الدخول.
  • العنوان / الوصف / الأيقونة / اللون — قابلة للتخصيص هنا.
  • ترتيب الظهور — رقم أصغر يظهر أولاً.

💾 9. الحفظ والمزامنة

  • كل عملية حفظ تطلب كلمة مرور اللوحة.
  • الإعدادات تُحفظ على الخادم وتُزامن لجميع المستخدمين خلال ثوانٍ.
  • الواجهة تتحدث تلقائياً دون الحاجة لإعادة تحميل.

📞 11. الدعم

  • الإشراف: الأستاذ الدكتور علي مجيد خضير الدهوي — عميد كلية الهندسة المدنية.
  • لأي طلب تعديل جوهري أو نظام معقّد، تواصل مع فريق التطوير.
